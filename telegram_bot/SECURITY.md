# Чек-лист безопасного запуска

## Обязательно

- Опубликовать правила розыгрыша и условие подписки до старта игры.
- Заменить название по умолчанию на полное наименование реального организатора/оператора,
  указать способ связи, сроки и порядок получения приза.
- Опубликовать `PRIVACY_POLICY.md` и правила розыгрыша по доступной участникам ссылке;
  при необходимости проверить их с профильным юристом по месту проведения.
- Добавить боту только право `manage_chat`; не давать публикацию, удаление, блокировку
  или назначение администраторов.
- Отключить добавление бота в группы через @BotFather (`/setjoingroups`).
- Оставить `EXCEL_PII_MODE=masked`, `DATA_RETENTION_DAYS=30` и
  `RATE_LIMIT_PER_MINUTE=20`.
- Перед каждым мероприятием выполнить `python -m telegram_bot security-check`.
- Запускать бота только из доверенной учётной записи Windows на доверенном компьютере.
- Не пересылать рабочую SQLite-базу, `.env`, `local_secret.key` и Excel третьим лицам.

## Что бот технически не умеет

- Писать в канал, группу или незапрошенный личный чат.
- Публиковать, редактировать или удалять посты канала.
- Добавлять пользователей или подписывать их автоматически.
- Рассылать сообщения по базе лидов.
- Принимать чужой контакт вместо номера владельца Telegram-аккаунта.
- Выдавать два промокода по одному QR-токену.

## Остаточный риск Telegram

Абсолютной гарантии отсутствия ограничений не существует. Telegram запрещает spam,
deception и social growth manipulation. Чтобы снизить риск спорной трактовки механики:

- подписка должна быть только на один официальный тематически связанный канал;
- условие не должно скрываться до момента победы;
- не требовать приглашать друзей, ставить реакции или повторять действия;
- проверять подписку только после явного нажатия пользователя;
- не отзывать уже выданный приз, если человек позже отпишется;
- не отправлять рекламные сообщения по собранным телефонам без отдельного согласия.

Актуальные правила: https://telegram.org/tos/bot-developers

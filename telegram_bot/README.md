# Telegram-бот Flexy Way

Локальный бот реализует цепочку: одноразовая ссылка игры → явное согласие на обработку
контакта → штатная передача своего телефона → подписка на официальный канал → одна
проверка по кнопке → атомарное резервирование промокода → отметка в Excel → выдача кода.

## Правила выдачи

- Один Telegram-аккаунт может получить только один приз.
- Тестировщик из `PRIZE_LIMIT_EXEMPT_USERNAME` может проходить выдачу многократно.
- Лимит проверяется при открытии новой ссылки и повторно внутри транзакции перед
  резервированием промокода.
- Удаление контактных данных не снимает отметку о ранее выданном призе.
- Общие условия показываются до согласия и повторяются в финальном сообщении:
  призы предназначены новым клиентам, кроме абонементов для всех клиентов; воспользоваться
  призом можно после пробного занятия; приз одноразовый и персональный; скидки и бонусы
  не суммируются с другими акциями.

## До публичного запуска

Условие подписки должно быть видно **до начала игры**, а не появляться впервые после
победы. Рекомендуемый текст на экране правил:

> Для получения приза победитель подписывается на официальный канал Flexy Way,
> подтверждает подписку в Telegram-боте и передаёт свой номер для связи по призу.

Приз должен реально существовать и выдаваться каждому победителю с валидной заявкой.
Нельзя добавлять рефералов, приглашения друзей, повторные подписки, автодобавление людей,
массовые рассылки или обещания несуществующего результата. Telegram прямо запрещает
спам, обман и social growth manipulation в
[Bot Developer Terms](https://telegram.org/tos/bot-developers).

## Настройка Telegram

1. Добавьте бота администратором официального канала. Для проверки `getChatMember`
   достаточно минимального административного статуса; не выдавайте права публикации,
   удаления сообщений, блокировки пользователей или добавления администраторов.
2. Безопасная ссылка добавления имеет вид:
   `https://t.me/USERNAME_БОТА?startchannel&admin=manage_chat`.
3. В @BotFather отключите добавление бота в группы: `/setjoingroups` → Disable.
4. Бот работает только в личных чатах и программно не может отправлять сообщения в
   группы или каналы.

Telegram гарантирует проверку других пользователей методом
[`getChatMember`](https://core.telegram.org/bots/api#getchatmember), когда бот является
администратором канала.

## Конфигурация

Скопируйте `telegram_bot/.env.example` в `.env` в корне проекта и заполните значения.
Секреты и локальная база исключены из Git. Безопасные обязательные настройки:

- `SUBSCRIPTION_REQUIRED=true` — без подтверждённой подписки выдачи нет;
- `EXCEL_PII_MODE=masked` — Excel получает псевдонимы и маску телефона;
- `DATA_RETENTION_DAYS=30` — контактные данные автоматически очищаются;
- `TOKEN_TTL_HOURS=24` — QR-ссылка быстро истекает;
- `RATE_LIMIT_PER_MINUTE=20` — защита от флуда.
- `PRIZE_LIMIT_EXEMPT_USERNAME=RRedactor` — единственный аккаунт для повторных тестов.

На Windows контакты, имена, Telegram ID, токены и ID игровых сессий защищаются DPAPI.
Мастер-ключ поиска защищён машинной областью DPAPI и ACL профиля, чтобы фоновой и
интерактивный процессы работали совместно; сами контактные значения шифруются в контексте
Windows-пользователя бота. Файл `telegram_bot/data/local_secret.key` нельзя удалять:
без него существующие заявки нельзя будет сопоставить и расшифровать.

## Запуск

```powershell
.\telegram_bot\setup_bot.ps1
.\telegram_bot\start_bot.ps1
```

Скрипт настройки создаёт изолированное окружение `telegram_bot/.venv`, чтобы зависимости
бота не конфликтовали с другими программами на компьютере. Бот работает через long polling:
входящий порт и публичный сервер не требуются. Одновременно разрешён только один процесс
бота — второй запуск будет остановлен блокировкой.

## Создание ссылки игры

```powershell
python -m telegram_bot token --prize SUB-L1-04-10 --session game-session-123 --json
```

Токен непрозрачный, одноразовый, не содержит номер приза и привязывается к первому
Telegram-аккаунту. В SQLite токен и ID сессии не хранятся открытым текстом. В Excel
попадают только необратимые короткие ссылки вида `token_...`, `session_...`, `tg_...`.

## Работа с контактами

Последние заявки показываются только в маскированном виде:

```powershell
python -m telegram_bot claims --limit 50
```

Полный контакт расшифровывается локально только для конкретного уже выданного кода:

```powershell
python -m telegram_bot contact --promo FW-EXAMPLE-0001
```

Пользователь может прочитать описание обработки данных командой `/privacy` и удалить
контактные данные командой `/delete_me`. После удаления остаётся только обезличенная
запись о факте выдачи, необходимая против повторного использования промокода.

Ручная очистка и проверка:

```powershell
python -m telegram_bot cleanup
python -m telegram_bot security-check
python -m unittest discover -s telegram_bot/tests -v
```

Не открывайте рабочий Excel во время выдачи: Microsoft Excel может заблокировать файл.
Бот не выдаст второй код при повторной попытке и покажет безопасное сообщение без
внутренних путей и деталей ошибки.

# Политика обработки данных Telegram-бота Flexy Way

> Перед публичным запуском замените «Flexy Way» на полное наименование реального
> организатора/оператора персональных данных и добавьте его официальный контакт.

## 1. Назначение

Бот обрабатывает данные исключительно для проверки заявки победителя, подтверждения
выполнения опубликованного условия подписки, выдачи приза и связи менеджера по вопросу
получения приза.

## 2. Какие данные обрабатываются

- технический Telegram ID и необратимый локальный псевдоним;
- имя, фамилия и username профиля, если они доступны;
- номер телефона, добровольно переданный штатной кнопкой Telegram;
- факт подписки на официальный канал в момент нажатия «Проверить подписку»;
- сведения о призе, промокоде и игровой сессии.

Бот не запрашивает пароль Telegram, одноразовые коды, платёжные данные, документы,
геолокацию или список контактов.

## 3. Согласие

До получения телефона бот показывает краткое описание обработки и отдельную кнопку
«Согласен и продолжить». Пользователь может отказаться; незавершённая заявка отменяется.
Согласие можно отозвать командой `/delete_me`.

## 4. Хранение и доступ

Контактные данные хранятся локально в зашифрованном виде. На Windows используется DPAPI
учётной записи, под которой запущен бот. В рабочем Excel по умолчанию сохраняются только
псевдонимы и маска номера. Доступ к расшифрованному контакту возможен локально только по
конкретному уже выданному промокоду.

Контактные данные автоматически удаляются через 30 дней после выдачи либо раньше по
запросу пользователя. Для предотвращения повторной выдачи сохраняется минимальная
обезличенная запись о факте использования промокода.

## 5. Передача и маркетинг

Данные не используются ботом для рекламных рассылок, не продаются и не передаются третьим
лицам, кроме сотрудников организатора, которым контакт необходим для выдачи приза, либо
случаев, прямо требуемых законом. Отдельное согласие на рекламу этой механикой не собирается.

## 6. Контакт и удаление

Контакт организатора: `@flexy_way`.

Команды бота:

- `/privacy` — краткое описание обработки;
- `/delete_me` — отзыв согласия и удаление контактных данных;
- `/help` — помощь по получению приза.
